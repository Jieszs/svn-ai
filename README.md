# svn-ai

`svn-ai` is an offline-first attribution and statistics system for code written with Claude Code and committed to Subversion.

The project is currently building its shared protocol and line-provenance foundation. It does not collect prompts, answers, transcripts, or complete source files.

See the [system design](docs/superpowers/specs/2026-09-08-svn-ai-attribution-system-design.md) and [Phase 1 plan](docs/superpowers/plans/2026-09-08-phase-1-core-protocol.md).
